# Keep / Remove / Merge / Simplify / Redesign

## Keep
Project, Shot, Scene, Task, Asset, Talent integration, Photographer role, RBAC/feature flags, autosaved demo data.

## Remove from primary UX
Separate-app feeling for Moodboard / Storyboard / Tasks; always-visible technical metadata; heavy toolbars; multiple primary CTAs.

## Merge
Moodboard references + storyboard planning entry into one Project Workspace navigation.

## Simplify
Shot creation starts with description; image and advanced metadata are optional. Tasks start from title only.

## Redesign
Overview, Board, Shots, Tasks, Files, Inspector and one-hand Shooting Mode.
