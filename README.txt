# Cast Iraq Full MVP

هذه نسخة Frontend كاملة قابلة للتجربة على GitHub Pages.

## الصفحات
- index.html — الصفحة الرئيسية
- auth.html — تسجيل الدخول / إنشاء حساب
- dashboard.html — داشبورد حسب نوع الحساب
- settings.html — إعدادات الحساب
- styles.css — التصميم
- app.js — المنطق
