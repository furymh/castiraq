# V13.4 SET Rebrand Audit

## Legacy identity found
- Cast Iraq name in document titles, footers, 404, Auth, app-generated header, admin preview and seed UI values.
- Legacy C brand mark in static and generated headers.
- Blue primary tokens and Instagram-blue verification.
- Light SaaS surfaces across V13, dashboard and workspace layers.

- User-facing product name → SET.
- New SET wordmark / compact production mark assets.
- Dark-first SET semantic token layer in `styles.set.css`.
- Lime primary action, focus, selected state and verification.
- Charcoal/Slate/Off-white/Steel surface hierarchy.
- PWA name/theme/icons and favicon.
- Marketing hero and Auth language shifted from casting-only to Creative Production Network.
- Global navigation and account UI use SET brand assets.
- Storyboard/workspace, discovery, profiles, forms, tables, sheets and Reels receive the shared SET layer.

- Demo email addresses ending in `@castiraq.demo` because authentication seed IDs are technical test data.
- Existing repository/URL paths are unchanged.
