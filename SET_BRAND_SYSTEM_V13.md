# SET Brand System — V13.4

## Brand idea
SET is a Creative Production Network: talent, photographers, directors, production companies and creative teams working in one connected product.

## Wordmark
Use `set-wordmark.svg` on desktop navigation, marketing, auth and footer. Preserve aspect ratio and clear space.

## Brand mark
Use `set-mark.svg` for compact mobile navigation, PWA/app icon, favicon and compact product surfaces.

## Core colors
- Charcoal `#0E0E10` — page background
- Slate `#1C1C20` — cards and panels
- Off White `#F5F5F5` — primary text
- Lime `#A6FF00` — primary action, active state, selection, verification
- Steel `#8A8D94` — muted metadata

Lime is an accent, not a page fill. Target <15% of the visual area.

## Typography
- Arabic / main product UI: Cairo
- English labels, technical metadata and wordmark support: Montserrat
- Avoid tiny body text and excessive uppercase.

## Components
- Primary button: lime fill + charcoal text
- Secondary: slate surface + subtle border
- Cards: slate, 1px border, restrained radius, no heavy shadows
- Active navigation: lime indicator
- Verification: lime badge, no Instagram blue
- Form focus: lime border/ring

## Photography
Use real production, filmmaking and professional portrait imagery. Never apply a global lime tint over skin or portfolio work.

## Do
- Dark-first layered surfaces
- Image-first profiles/storyboard
- Progressive disclosure
- High-contrast shoot-day controls

## Don't
- Lime everywhere
- Heavy glows, film grain, lens-flare gimmicks
- Random white SaaS cards inside dark pages
- Old blue brand accents
