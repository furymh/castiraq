# Cast Iraq V8 — Competitive UX Matrix

| Area | Cast Iraq V8 | Casting Networks | Backstage | Spotlight | Instagram | V8 decision |
|---|---|---|---|---|---|---|
| Talent discovery | Search + filters + match score | Deep project/submission filtering | Search filters + invite favorites | Professional performer directory | Explore/suggested content | Keep filters professional, presentation social-first |
| Profile | Media + facts + credits + portfolio | Detailed profile + audition history | Detailed talent profiles | Media-prominent profile, Highlights, social link | Profile grid + Reels tab | Media-first profile with professional casting facts |
| Casting workflow | Applications → Selected → Self-Tape → Booked | Submissions, statuses, Worksheet, requests, scheduling | Applications, shortlists, self-tapes, schedules, messaging | Self-Tape request/receive/share | N/A | Keep professional workflow behind simple UX |
| Social content | Feed, Reels, likes, comments, saves | Limited social discovery | Limited social discovery | Instagram link, media | Feed, Explore, Reels, save/share/comment | Use Instagram interaction model without turning casting into popularity contest |
| Scheduling | Demo schedule module | Audition/callback schedules + autofill | Audition scheduling | Self-tape workflow | N/A | Preserve schedule as company tool, not public clutter |
| Admin control | Feature flags, RBAC, widgets, logs | Enterprise workflow controls | Team tools | Account/admin tools | Content controls | Centralize controls in System Control |
| Mobile navigation | Bottom nav, role-aware center action | Web/app workflow | Responsive web | Responsive account tools | Bottom nav / one-hand use | Keep five destinations max; dynamic by feature/role |
| Feature visibility | Role + platform + nav controls | Product-level access patterns | Account/team access | Account type restrictions | Account/privacy rules | Configuration-driven, not hardcoded UI only |

## Sources used in audit
- Casting Networks: project submissions, statuses, self-tape/media requests, scheduling, Worksheet.
- Backstage: flexible talent search, invite to apply, self-tapes, shortlists, audition schedules, messaging.
- Spotlight: 2026 profile redesign with more prominent media, Instagram integration, Self-Tape improvements.
- Instagram/Meta: Feed suggestions, Explore/Reels discovery, separate Reels profile surface, like/comment/share/save interaction model.
