# Cast Iraq Web MVP

نسخة ويب تجريبية Static لمشروع منصة Casting عراقية.

## التشغيل
افتح ملف `index.html` مباشرة بالمتصفح.

## الموجود حالياً
- صفحة رئيسية
- قاعدة مواهب تجريبية
- بحث وفلترة
- بروفايل موهبة
- Shortlist تجريبي
- Casting Calls
- إضافة فرصة Casting
- Responsive للموبايل

## المرحلة التالية
ربط الموقع بـ Supabase لإضافة:
- تسجيل الدخول
- حسابات المواهب والشركات
- رفع الصور والفيديو
- قاعدة بيانات حقيقية
- Shortlists محفوظة
- إشعارات
- اشتراكات ودفع
